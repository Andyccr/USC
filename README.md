# USC

纯文本浏览器。打开 `index.html`，直接输入就能搜。

页面收成可阅读的文字，链接是 `[1] [2]`。图片默认不加载。没有服务器、没有索引。

## 打开

用浏览器打开 `index.html`，或：

```bash
python3 -m http.server 8765
```

访问 `http://127.0.0.1:8765/`。

## 怎么用

底部输入框就是搜索框。

- 输入文字，回车：搜 Google、Bing、百度
- 输入网址，回车：打开页面
- 输入数字，回车：跟随第 n 个链接
- 输入时会出现联想；↑/↓ 选择，Tab 补全，回车搜索

```
› 量子计算
› example.com
› 1
› back
```

不需要先打命令。`help` 看其余快捷方式。

## 少而够用的命令

| | |
|---|---|
| `back` `home` `help` | 后退、首页、说明 |
| `i 1` / `i all` / `i on` | 加载一张图 / 全部 / 以后自动出图 |
| `g` `b` `d` + 词 | 只搜 Google / Bing / 百度 |
| `s <词>` | 强制把 `back`、`home` 等命令名当搜索词 |
| `proxy on` / `proxy off` | 允许 / 禁止通过 Jina 读取跨域页面 |
| `:…` | 任何命令都可以加冒号，避免和搜索词冲突 |

图片占位符也可以直接点击加载。其余（书签、查找、源码、另存）仍可用，见 `help`。

普通链接在本页打开；搜索引擎链接会交给系统浏览器。浏览器自带的后退/前进按钮与 `back` / `forward` 都可使用。输入框为空时，空格翻页。Esc 清空输入。

## 跨域与隐私

默认只从你的浏览器直接读取页面。很多网站不允许跨域读取，这时 USC 不会自动把网址交给第三方。

输入 `proxy on` 后，直接读取失败的 URL 会发送给 [Jina Reader](https://r.jina.ai/)；状态栏会显示 `via jina`。输入 `proxy off` 可随时关闭。这个选择保存在本机浏览器。

## 文件

```
index.html    界面
browser.js    抓取与排版
usc.js        输入、搜索、历史
usc.test.js   测试
```

```bash
node usc.test.js
```

## 限制

部分站点会拒绝直接抓取；可选择开启 Jina，或在系统浏览器打开。页面加载 15 秒后会停止，缓存最多保留 20 页。超过约 12 万字符的正文会标记为截断。书签、代理和出图偏好只存在本机浏览器里。
