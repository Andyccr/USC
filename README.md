# USC

纯文本浏览器。打开 `index.html`，直接输入就能搜。

页面收成可阅读的文字，链接是 `[1] [2]`。图片默认不加载。没有服务器、没有索引。

## 打开

用浏览器打开 `index.html`，或：

```bash
python3 -m http.server 8765
```

访问 `http://127.0.0.1:8765/`。

## 怎么用

底部输入框就是搜索框。

- 输入文字，回车：搜 Google、Bing、百度
- 输入网址，回车：打开页面
- 输入数字，回车：跟随第 n 个链接
- 输入时会出现联想，Tab 补全第一条

```
› 量子计算
› example.com
› 1
› back
```

不需要先打命令。`help` 看其余快捷方式。

## 少而够用的命令

| | |
|---|---|
| `back` `home` `help` | 后退、首页、说明 |
| `i 1` / `i all` / `i on` | 加载一张图 / 全部 / 以后自动出图 |
| `g` `b` `d` + 词 | 只搜 Google / Bing / 百度 |
| `:…` | 任何命令都可以加冒号，避免和搜索词冲突 |

其余（书签、查找、源码、另存）仍可用，见 `help`。

点链接在本页打开；Ctrl/Cmd 点击用系统浏览器。输入框为空时，空格翻页。Esc 清空输入。

## 文件

```
index.html    界面
browser.js    抓取与排版
usc.js        输入、搜索、历史
usc.test.js   测试
```

```bash
node usc.test.js
```

## 限制

部分站点（尤其是 Google 结果页）会拒绝抓取。这时页面会留下可点的 URL；联想词仍可用。书签和出图偏好存在本机浏览器里。
